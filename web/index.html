Marketplace launch controls

  • US and Dubai inventories are stored separately with USD/AED currency validation.
  • Public search exposes only verified and published records through a restricted database view.
  • Dubai listings capture RERA ORN and DLD permit references; US listings capture state licensing references.
  • Automated property-feed imports, MLS/IDX, DLD data partnerships, image storage and public enquiry intake require separate provider/API work and permissions.
  • Property agents must confirm ownership or written advertising authority; SocialOS does not itself act as a broker.

Security checklist

  • Tenant-scoped RLS policies on current data tables.
  • Owner-only team drafts; member-level RBAC not yet activated.
  • Audit events are append-only for normal authenticated users.
  • Leaked-password protection is currently disabled in Supabase Auth; enable before broad production rollout.
  • OAuth token vault, MFA enforcement and restore drills remain launch gates.
  • Review US privacy, TCPA, CAN-SPAM and state-specific obligations before outbound use.
